
# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior to identify purchasing patterns, customer segments, product performance, and factors influencing spending. It uses Python, SQL, and Power BI to transform raw customer data into meaningful business insights.

## Objectives
- Analyze customer purchasing patterns and spending behavior.
- Understand revenue trends across customer demographics.
- Evaluate the impact of discounts and shipping methods.
- Identify highly rated and frequently purchased products.
- Analyze customer loyalty and subscription behavior.
- Build a Power BI dashboard for business insights.

## Tech Stack
- Python
- Pandas
- Jupyter Notebook
- Microsoft SQL Server
- SQLAlchemy
- PyODBC
- Power BI

## Project Workflow

### 1. Data Exploration
- Loaded the dataset using Pandas.
- Examined data types, summary statistics, and distributions.
- Identified missing values and potential data quality issues.

### 2. Data Cleaning and Feature Engineering
- Handled missing review ratings using category-wise median imputation.
- Standardized column names.
- Created age groups for demographic analysis.
- Converted purchase frequency categories into numerical day intervals.
- Removed a redundant promotional-code field after examining its relationship with the discount field.

### 3. SQL Analysis
Used SQL Server to answer business questions, including:

- Revenue generated by male and female customers.
- Customers who used discounts but spent above the average purchase amount.
- Products with the highest average review ratings.
- Spending differences between standard and express shipping.
- Comparison of subscribers and non-subscribers.
- Products with the highest discount usage rates.
- Customer segmentation into new, returning, and loyal customers.
- Top three purchased products within each category.
- Relationship between repeat purchases and subscriptions.
- Revenue contribution by age group.

**SQL concepts used:**
- SELECT, WHERE, GROUP BY, ORDER BY
- Aggregate functions
- CASE statements
- Subqueries
- Common Table Expressions (CTEs)
- Window functions

### 4. Power BI Dashboard
Created a dashboard to visualize customer shopping behavior and support data-driven decision-making.

The dashboard focuses on:
- Customer spending patterns
- Product performance
- Customer demographics
- Purchase behavior
- Discounts and subscriptions

## Business Value
The analysis helps businesses understand customer preferences, evaluate promotional strategies, identify valuable customer segments, and make informed decisions about marketing, product strategy, and customer retention.

## How to Run the Project

### Prerequisites
- Python 3
- Jupyter Notebook
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Microsoft Power BI Desktop

### Step 1: Clone the Repository
```bash
git clone <your-github-repository-url>
cd "Data Analytic Portfolio Project"
```

### Step 2: Install Dependencies
```bash
pip install pandas sqlalchemy pyodbc jupyter
```

### Step 3: Run the Notebook
```bash
jupyter notebook
```

Open `Customer_Shopping_Behavior_Analysis.ipynb` and execute the notebook cells.

### Step 4: Configure SQL Server
- Create a database named `customer_behavior`.
- Update the database connection settings in the notebook.
- Load the processed dataset into SQL Server.

### Step 5: Run SQL Queries
Open `DataAnalysis.sql` in SQL Server Management Studio and execute the queries after confirming the database and table names.

### Step 6: Open the Dashboard
Open `Dashboard.pbix` in Power BI Desktop and configure the data source if necessary.
